# jh-zsh-theme

Personal zsh + [Powerlevel10k](https://github.com/romkatv/powerlevel10k) setup, packaged so a
brand-new machine can be bootstrapped in one command instead of re-running `p10k configure` and
re-downloading fonts by hand every time.

```bash
git clone https://github.com/githubhjs/jh-zsh-theme.git
cd jh-zsh-theme && ./install.sh
```

This installs (or reuses, if already present): oh-my-zsh, the Powerlevel10k theme, this repo's
`p10k.zsh` config, the `ZSH_THEME` + instant-prompt wiring in `~/.zshrc`, and the MesloLGS NF font
(system-wide with sudo, user-local fallback otherwise, `~/Library/Fonts` on macOS). Existing
`~/.zshrc` / `~/.p10k.zsh` are backed up with a timestamp before anything is touched — never
silently overwritten. Safe to re-run.

## What style this is

Wizard options (as self-described by the original generated file):

> nerdfont-v3 + powerline, small icons, rainbow, unicode, 24h time, round separators, blurred
> heads, round tails, 2 lines, solid, left frame, dark-ornaments, sparse, many icons, fluent,
> instant_prompt=verbose

Base preset: Powerlevel10k's own bundled `config/p10k-rainbow.zsh`.

## ⚠️ Important: this `p10k.zsh` is a reconstruction, not a byte-exact copy

The original file was generated by `p10k configure` on 2026-09-17 across a shared `$HOME`
(Some machiinese) — 1840 lines, 95716 bytes, md5 `54e88bcc403df6138a8ab960200b3c84`.

That exact file wasn't directly copied into this repo. Instead, it was reconstructed here by
taking the same base preset (`p10k-rainbow.zsh`) and re-applying the following changes, derived
from a line-by-line diff against that base:

- Enabled `os_icon` (left prompt, line #1 — was commented out in the base preset)
- Enabled `vi_mode` (right prompt — was commented out)
- Enabled `time` (right prompt, line #1 — was commented out)
- `POWERLEVEL9K_MODE`: `nerdfont-complete` → `nerdfont-v3`
- `MULTILINE_*_PROMPT_PREFIX` color: `%242F` → `%240F` (darker ornaments)
- `MULTILINE_*_PROMPT_SUFFIX`: cleared entirely (left-frame-only look — no right-side box border)
- `MULTILINE_FIRST_PROMPT_GAP_CHAR`: `' '` → `'─'` (horizontal rule instead of blank space)
- `MULTILINE_FIRST_PROMPT_GAP_FOREGROUND`: `242` → `240`
- Separator glyphs switched from sharp powerline arrows (`\uE0B0`-`\uE0B3`) to the
  round/blurred set (`\uE0B4`-`\uE0B7`), plus solid gradient-block segment caps `▓▒░` / `░▒▓`

If you compare this file against the real original and find a mismatch, that's expected — treat
this as a very close starting point, not a guarantee of pixel-parity. Fastest way to true it up:
run `p10k configure` once (interactive wizard, needs a real terminal — can't be scripted) and
re-diff the result against `config/p10k-rainbow.zsh` in your local powerlevel10k clone, then
replace `p10k.zsh` in this repo with whatever that produces.

## Manual install (if you don't want to run install.sh)

1. Install oh-my-zsh if you don't have it, then clone Powerlevel10k as a custom theme:
   ```bash
   git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \
     ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/themes/powerlevel10k
   ```
2. In `~/.zshrc`, set `ZSH_THEME="powerlevel10k/powerlevel10k"`.
3. Copy `p10k.zsh` from this repo to `~/.p10k.zsh`.
4. Prepend `snippets/instant-prompt.zsh` to the very top of `~/.zshrc` (must be above everything
   else that might print to stdout or prompt for input).
5. Append to the end of `~/.zshrc`:
   ```zsh
   [[ ! -f ~/.p10k.zsh ]] || source ~/.p10k.zsh
   ```
6. Install the MesloLGS NF font (`install-fonts.sh` in this repo, or see below) and set it as your
   **terminal emulator's** font — not just on the machine zsh is running on.

## Fonts

```bash
./install-fonts.sh
```

Downloads the 4 official MesloLGS NF weights from
[`romkatv/powerlevel10k-media`](https://github.com/romkatv/powerlevel10k-media) and installs them
system-wide (Linux, if sudo available) or user-local otherwise.

**Critical caveat if you connect over SSH**: installing the font on the *server* only matters if
you're looking at that machine's own local display. If you SSH into it from a laptop/desktop
terminal (iTerm2, Windows Terminal, GNOME Terminal, etc.), the prompt's glyphs are drawn by *that
terminal app* using *its own* fonts — you also need to install MesloLGS NF on the client and set
it as the terminal's font, or the icons render as boxes/`?` regardless of what's installed
server-side.

## zsh version notes (from a real multi-machine audit, not assumption)

Powerlevel10k requires zsh ≥ 5.1 (`internal/p10k.zsh` enforces this), and oh-my-zsh recommends
≥ 5.0.8. But zsh **5.5.x–5.7.1** specifically falls inside two documented "known-bad" workaround
ranges baked into Powerlevel10k's own source (search `_p9k_prompt_overflow_bug` in
`internal/p10k.zsh`) — it still works, but only via an internal workaround path, not the clean
path that 5.7.2+ / 5.8+ get. If a machine's `/bin/zsh` reports a version in that 5.5–5.7.1 range
(RHEL 8.x's stock zsh is a common example — ships 5.5.1), prefer building/using a newer private
zsh (5.8+) for that user if one is already available on the box, rather than assuming the stock
one is "good enough" just because it clears the bare 5.1 minimum.
